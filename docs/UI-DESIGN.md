# 界面设计说明（清新七彩）

2026-09-29 重做。只改外观和交互动效，功能、设置项、数据格式都没动；所有 id 和测试依赖的 class 保持不变。

初版是深色「极光玻璃」（霓虹渐变、流动色块、光球）。用户看过后的意见是「七彩的可以做得清新一点，现在的太抽象」，于是改成现在的浅色马卡龙：七彩只做点缀，图形都用具体的东西（画布、画笔、胶片、照片白边），不再用抽象色块。

## 视觉语言

| 项 | 取值 | 用在哪 |
| --- | --- | --- |
| 马卡龙七彩 | 樱花 `#ffb3c7` · 蜜桃 `#ffcf9f` · 柠檬 `#ffe799` · 薄荷 `#a3e4cc` · 天蓝 `#9bd4f7` · 丁香 `#c4b5ff`（`--st-ai-rainbow`） | 标签页下划线、标题栏细线、进度条、描边、选中的筛选按钮、声波 |
| 主按钮渐变 | `--st-ai-cta`：`#4fb0ff → #8b8dff → #f58bbf`（深一点，白字看得清） | 生成、保存、播放键、品牌标 |
| 面板 | 白色磨砂 `rgba(250,251,255,.88)` + 四角淡淡的马卡龙晕染（静态），白卡片 + 细边 + 冷色柔影 | 设置面板、媒体库、提示词编辑 |
| 文字 | `--st-ai-ink` `#283044` / `-2` `#5c6479` / `-3` `#8e95aa` | 面板里的文字 |
| 卡片色调 | 薄荷、天蓝、樱花、蜜桃、柠檬、丁香（`data-tone`） | 卡片标题前的图标 |
| 色相取值 | `hueOf(text)`：170°–330°（青→蓝→紫→粉） | 语音卡、视频封面的马卡龙底 |

所有字号仍是 `--mainFontSize` 的倍数（跟着酒馆的字体缩放）；手机上面板内缩一号，和以前一样。

## 组件

- **正文生成按钮**（`.st_gpt_inline_gen` / `.st_ai_media_gen`）：半透明胶囊 + 七彩描边 + 渐变圆形图标；图片按钮带提示词摘要，配音按钮带情绪。悬停时浮起、扫过一道光。
- **生成中卡片**（`src/ui/fx.js` 的 `developCard`）：按钮原位变成按尺寸比例占位的白色「画布」——网点、四角马卡龙晕染、一道柔光从左扫到右、白圆里轻轻晃动的画笔（视频是胶片）、状态、已等待时间、七彩进度条。视频有百分比时显示大号渐变数字和确定进度。
- **正文图片**（`.st_ai_img_frame`）：圆角卡片；桌面端下面垫一张同图模糊副本做淡淡的同色光晕；悬停浮出提示词和白色玻璃工具条（触屏常驻）。刚生成的图等加载完再「从模糊中显影」并扫光；重新生成时画面变淡、光带来回扫。
- **语音胶囊**（`.st_ai_voice_chip`）：渐变播放键 + 天蓝进度环 + 14 根声波（按台词算出的固定高度，不为画波形去下载音频）；播放到哪儿，哪儿的声波亮成七彩并跳动，台词下面长出一条七彩下划线。台词用酒馆的引号色。
- **视频卡片**（`.st_ai_video_frame`）：不预读（`preload=none`，媒体只在播放时加载），封面是按描述取色的马卡龙渐变 + 上下两排胶片齿孔 + 白色播放键 + 描述；开播后收起封面、交给原生控件。
- **预览层**：浅色。同图重度模糊再盖一层白纱，把画面颜色晕染成马卡龙色；照片带一圈白边，从缩略图位置放大进来（FLIP）；滚轮以指针为中心缩放、双击 1×/2.2×、拖动平移、双指捏合、`+` `-` `0` 键；底部白色玻璃条显示提示词，可展开、复制。语音预览是「正在播放」卡片。
- **面板**：品牌标（渐变圆角方块）、标签页白色滑块 + 七彩下划线（`syncTabIndicator`）、标题栏下一条七彩细线、按用途分组的白卡片、薄荷→天蓝的拨动开关、聚焦时天蓝描边的输入框、聚焦时七彩描边的输入区。
- **媒体库**：像一面照片墙——带白边的照片卡，最新一项放大成 2×2（手机上横跨两列、宽屏比例）；语音卡是马卡龙底 + 七彩声波，可在卡片上直接播放；视频卡是马卡龙底 + 胶片齿孔；选中的筛选按钮是七彩描边，按钮上显示每类数量；入场依次浮现。

## 性能规则（不拖慢酒馆）

- 一直在动的只有：生成中的卡片、正在播放的语音。面板打开时也没有常驻动画（晕染是静态的）。聊天静止、面板关闭时扩展没有任何运行中的动画（`document.getAnimations()` 实测为 0）。
- 动画只动 `transform` / `opacity`；模糊只用在静态层上。
- 播放进度用 `requestAnimationFrame`，停了就不再排下一帧；等待计时共用一个 rAF，页面上没有生成中卡片就停。不留 `setTimeout` / `setInterval`（测试会查）。
- 媒体文件只在播放时加载：视频封面不预读，声波是算出来的。
- 光晕只在桌面端开；`data:` 地址的图不复制光晕。

## 兼容

- **酒馆「快速 UI 模式」**（默认开启）会给 body 加 `no-blur`，并用 `!important` 关掉所有 `backdrop-filter`。扩展尊重这个选择：`body.no-blur` 下半透明层换成近乎不透明的底色（见 `style.css` 末尾）。
- **酒馆会把正文里的 `<i>` 染成 `--SmartThemeEmColor`**（`.mes_text i` 是给斜体用的，但 Font Awesome 图标也是 `<i>`）。`style.css` 用 `.mes_text :where(...) i { color: inherit }` 让图标跟着各自的按钮走。
- **酒馆的 `.mes_text img:not(.mes_img)`** 会把正文图片撑到整屏高，新样式用 `#chat .st_ai_img_frame > img.st_gpt_inline_img` 盖过去。
- **深浅主题**：正文里的按钮、胶囊用 `--SmartThemeBodyColor` 做底色和文字（`color-mix`，旧浏览器有回退）；生成中卡片、视频封面、面板本身是浅色画布。
- **减少动态效果**（`prefers-reduced-motion`）：所有动画和过渡立即结束。
- **触屏**（`hover: none`）：工具条、操作按钮常驻（缩小一号）；手机不开光晕。
- 装饰性文字（提示词摘要、图片说明、视频描述、角标）用 CSS `attr(data-text)` 画出来，不进消息的 DOM 文本：扫描器比对消息文字、复制消息都不受影响。
